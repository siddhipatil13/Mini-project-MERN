LEARNSPACE LMS - RUN ON WINDOWS (PowerShell, inside this folder)

1) One time setup
   Copy-Item server\.env.example server\.env
   notepad server\.env        (set MONGODB_URI and JWT_SECRET, save)
   npm run install:all

2) One time: create admin + sample and programming-language courses
   npm --prefix server run seed

3) Start the local Piston API and install runtimes for coding tests (see README.md).

4) Start the app (every time)
   npm run dev

Open http://localhost:5173
Admin login: the ADMIN_EMAIL / ADMIN_PASSWORD you set in server\.env

UPDATING FROM AN OLDER VERSION
- Copy your old server\.env into the new server folder.
- Run:  npm run install:all   (new packages: nodemailer, pdfkit)
- Then: npm run dev
- Emails: see the "Emails (v4)" section in README.md
